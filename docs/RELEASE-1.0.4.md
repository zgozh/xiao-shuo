# 勾彬小说 1.0.4

- 搜索首页增加「全部书源／日本轻小说」范围选择；搜索页原有分组菜单仍可使用。
- 新增 Novelia 文库适配，支持搜索中文译名、查看详情、选择中文 EPUB 卷册并用本地阅读器阅读。EPUB 来源与章节型来源分别保留原有流程。
- 参考 Yolo 开源规则接入拷贝轻小说，修正搜索分页，按网站的卷册与章节行号拆分正文，保留独立插图，缓存分卷文本以避免每章重复下载整卷。
- 将现有 ESJ Zone 归入日本轻小说组，发现页增加独立日轻栏目，仅使用该组来源；ESJ 栏目只取日轻分类。
- 书源中心增加 ZWolken 社区日轻译本、日文原版合集的按需预览导入，并自动补充分组。候选合集不代表逐源可用，部分需登录或验证。
- 沿用应用包名和签名，版本代码提升至 5，支持覆盖升级；迁移仅插入缺少的来源及补充 ESJ 分组，不替换用户规则或启停设置。

Novelia 在本次环境直连被重置，通过现有代理访问成功；无账号要求不等于任意网络都可直连。仅公开中文 EPUB 卷册接入本规则，机翻生成及受限接口未接入。书目没有中文 EPUB 时不会自动替换为机翻或其他作品。

接口预检样本：《回复术士的重启人生》（月夜涙，9 个中文卷册）、《无职转生～蛇足篇～》（1 个中文卷册）、《义妹生活》（10 个中文卷册）。三者均下载一卷验证 EPUB 容器和正文文档；这不是全部卷册的内容完整性保证。

拷贝来源另外验证《回复术士》9 个卷册条目、《义妹生活》18 个条目（包含额外条目，末条为第16卷），并分别检查首、末卷 TXT 编码及所有文本章节的边界。发现接口返回 21 本。不能把来源条目数等同于本篇卷数，也不据此承诺整套无缺漏。详细选型见 `LIGHT-NOVEL-SOLUTIONS.md`。
