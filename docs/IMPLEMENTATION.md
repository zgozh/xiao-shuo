# 已确认的产品与验收范围

用户确认：复用成熟开源 Android 阅读器；应用名为“勾彬小说”；无广告，独立包名，GitHub 源码与签名 APK 发布。

优先级：聚合搜索和书源质量优先；其次为书架、原生阅读器、发现广场与榜单；个人统计及推荐使用本机数据。主页简洁，字体、背景和排版等高级设置集中管理。

推荐与榜单必须注明来源：书源榜单来自真实响应；个人推荐仅针对本地待读书架按近期作者和分类排序，不编造热度或全网排名。

## 实现顺序

1. 引入并标记上游源码，保留 GPL 与来源。
2. 独立应用标识、移除 Firebase 统计依赖、隔离更新与发布签名。
3. 聚合搜索入口、来源诊断、书源目录与默认规则。
4. 发现广场、阅读面板与深度主题设置入口。
5. 构建、定向测试、模拟器核心流程验证、签名与发布。

## 验证范围

V3：本次涉及应用启动、导航、签名、共享搜索回调和最终 APK 交付。

检查：调试/正式 APK 构建；新增目录与正文质量检查测试；现有搜索进度、分页及命令隔离测试；阅读行距测试；模拟器检查启动、导航、主题入口，以及真实搜索、加书和阅读链路。外部书源故障需要记录，不以下载规则成功代替可用性验证。

产品实现由主会话直接完成并审查；当前仅 research skill 明确授权了独立研究代理，因此实施任务未委派。书源研究代理返回的材料由主会话整理入库。
