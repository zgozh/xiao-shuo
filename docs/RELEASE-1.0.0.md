# 勾彬小说 1.0.0

基于 Legado 开源底座二次开发的无广告 Android 小说阅读器，支持 Android 8.0 及以上。

- 书架、发现广场、全源搜索、阅读面板与设置五个入口。
- 320 条内置规则，310 条按当前快照启用，包含筛选的 300 条中文小说候选。启用状态与本机检测结果分开显示；支持更多社区集合、网络/文件/二维码导入和订阅更新。
- 搜索书名或作者，合并同名同作者结果，查看各来源的命中、耗时与失败原因。
- 换源保留已有结果并主动刷新，逐步加载目录与正文证据，按检测提示、响应时间与用户偏好排序。
- 字体、背景、配色和排版深度自定义；提供 8 套常用阅读风格模板。
- 累计阅读时长、最近阅读、个人排行、待读推荐，保留离线缓存、听书、书签、RSS 和 WebDAV 等能力。

本机模拟器搜索界面观察到：《执魔》/我是墨水 48 个来源、《万古神帝》/飞天鱼 54 个来源、《九龙至尊》/盘古 23 个来源。数字反映当时的搜索命中，不表示这些来源的每个章节均已验证完整；网站与网络变化可能影响后续结果。

使用独立包名 com.zgozh.xiaoshuo 和本机生成的发布签名；签名私钥不在仓库中。完整源码及 GPL-3.0 许可随本仓库提供，详见 README、LICENSE 和书源调研记录。
