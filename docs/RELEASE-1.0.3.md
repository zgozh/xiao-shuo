# 柘栯小说 1.0.3

修复全源搜索进行中改词、重新提交后，列表长时间显示旧结果或返回重进后空白的性能回退。

1.0.2 把书名/作者规范化也用于列表差分的逐项比较。结果较多、持续重排时，同一批文本会被重复做正则规范化；旧差分任务在共用后台队列积压，新页面的列表更新也要等待。设备线程快照中，两个列表更新线程都在 `BookIdentityKt` / 正则匹配栈上，分别已累计约 110 秒 CPU 时间。

- 规范化去重保留在合并阶段；显示列表改为比较合并结果保留的首个书籍地址，避免高频差分比较再次做正则处理。
- 重新提交搜索时立即清空旧显示列表并回到顶部，清除旧的列表位置与差分代次。
- 搜索诊断显示合并结果、显示列表及已绑定条数；列表提交或合并异常写入应用日志。
- 增加列表身份合同测试，并确认跨源合并继续保留同一代表对象及地址。
