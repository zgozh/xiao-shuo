## 限制

### 搜索计时

应用已打开、310 条启用规则，使用应用外 ADB 计时；以数据库出现本轮正确书名/作者的新结果作为首个命中，以搜索进度控件结束作为全源完成。轮询带来约 1 秒采样误差；每本各测一次，不清除 HTTP 缓存。

| 作品 | 首个正确结果 | 全源完成 | 本轮数据库观察到的独立 origin |
| --- | ---: | ---: | ---: |
| 执魔 | 1.17 秒 | 33.59 秒 | 46 |
| 万古神帝 | 1.20 秒 | 38.34 秒 | 52 |
| 九龙至尊 | 2.16 秒 | 39.03 秒 | 24 |
| 平均 | 1.51 秒 | 36.99 秒 | — |

计时轮次与前面的首次界面观察不是同一轮；来源响应和合并数可能变化。

搜索命中、目录可读、抽样正文可读和整本完整是不同层次；不把前者当成后者。外部网站、授权范围、登录和网络条件会改变结果。

书源目录刷新需要本仓库 main 分支发布后才能请求到自己的远端索引；离线内置目录与规则快照可独立使用。

最终交付 APK 的哈希以 `downloads/SHA256SUMS.txt` 为准。发布私钥与个人 SDK/代理配置均不提交。
