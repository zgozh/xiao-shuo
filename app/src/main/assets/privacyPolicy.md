# 柘栯小说隐私说明

* 应用无需注册，没有自建账号服务器；此分支已移除 Firebase 统计依赖。
* 书架、进度、书签与阅读记录默认保存在本机。崩溃和诊断日志保存在本机，用户可自行导出。
* 使用搜索、发现、正文获取、网络听书、规则更新或应用更新时，应用会请求相应网站或服务；对方会收到请求所需的搜索词、网络地址等信息，具体行为取决于所使用的书源与服务。
* WebDAV 备份使用用户自行配置的服务器，只有启用同步或备份时才向该服务器传输相应数据。
* 文件访问用于导入电子书、字体、背景、规则和备份。通知、前台服务与音频权限用于下载、检测及听书等功能。
* 书源可包含 JavaScript，请使用可信维护者的规则。不要在不可信书源中输入账号、口令或个人信息。
* 项目源码、问题反馈和版本发布：https://github.com/zgozh/xiao-shuo
